# Local inference backends
# Pinned to 0.5.1 deliberately, NOT the latest release: foundry-local-sdk had a breaking
# API redesign at 1.0.0 (package/import renamed foundry_local -> foundry_local_sdk, and
# the simple FoundryLocalManager(alias).endpoint/.api_key + plain openai.OpenAI(...) client
# pattern was replaced by a singleton Configuration/native-interop API). Verified by
# downloading and inspecting both wheels directly: 0.5.1 is the last version matching the

# pattern that rag/embedder.py and rag/generator.py are written against. If you deliberately

# Configuration/EmbeddingClient/ChatClient API instead.
